# 主循环

上电后程序只做三件事：配硬件、建业务、然后一直转。

## 启动顺序

```mermaid
flowchart TB
    reset[上电复位] --> init[board_init<br/>配时钟和串口]
    init --> appinit[app_init<br/>先语音，再读卡]
    appinit --> loop{主循环}
    loop --> process[app_process<br/>推进一步]
    process --> idle[board_idle<br/>睡到下次中断]
    idle --> loop
```

对应代码在 [[src-main.c]] 的 `main`。

## 每一圈做什么

`app_process` 在 [[src-app.c]]。顺序固定：

```mermaid
flowchart LR
    drain[倒空 RFID 缓冲<br/>最多 128 字节] --> rtick[rfid_reader_tick]
    rtick --> ttick[tts_service_tick]
    ttick --> bp[board_process<br/>关灯和电机]
```

1. 把 USART1 环形缓冲里的字节喂给读卡状态机。上限是缓冲长度，避免中断一直进数时卡在这里。
2. 推进读卡状态机。
3. 推进语音队列。
4. 推进板级定时：到点关灯，开了电机就推电机。

## 为什么不阻塞

读卡、语音、灯都用时间戳和状态机。没有 `delay`，没有死等。

主循环空了就调 `board_idle`，让 CPU 睡到下一次中断。唤醒源是 SysTick 和 USART1，最坏睡 1 ms。

## 时间从哪来

`board_millis()` 读 HAL 的毫秒计数。SysTick 每 1 ms 加一次。到 2^32 会翻回 0，比较时间时已经处理了翻转。
