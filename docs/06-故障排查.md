# 故障排查

先看现象，再对下面的表。

## 完全没反应

灯不亮，串口没动静。

可能原因：

- 没烧进去。重新走 [[05-编译烧录]]。
- 外部 8 MHz 晶振没起振。程序会停在时钟配置那里。
- 下载器没接对。`SWD` 口要接 `PA13`、`PA14`、`NRST`、地、3.3 V。

## 灯常亮或全不亮

指示灯按低电平点亮来写，接在 `PA8`。

- 常亮：可能极性反了，或灯实际不在 `PA8`。
- 全不亮：可能没读到卡，或灯座接线不对。

## 刷卡不播报

按顺序查：

1. `SW1` 要打开。它管播报器电源，关上时模块没电。
2. 读卡器接的是 `H1`，不是别的插座。
3. 模块 TX 接单片机 `PA10`，模块 RX 接 `PA9`。
4. 语音走 `PA2` / `PA3`，接在 `U7`。
5. 波特率是 9600。
6. 卡片文字是 GB2312。非法编码不会念。
7. 同一张卡一直放着只念一次。拿走再放回才会再念。

## 播报被截断

文字按显式长度发送。若还是截断，看语音模块是不是收满了。

`board_rfid_rx_overflow_count()` 一直在涨，说明主循环慢了，RFID 字节丢过。

## 电机不转

- 默认就是关的。要开，见 [[05-编译烧录]] 的电机测试。
- 驱动芯片的唤醒脚不在 MCU 上。只出 PWM，电机不一定转。
- 先确认板上开关和驱动接线，再上电。

## 串口丢字节

`board_rfid_rx_overflow_count()` 返回丢字节的累计次数。

- 一直是 0：主循环跟得上。
- 在涨：主循环慢了，或波特率不对。
