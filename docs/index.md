# 固件文档首页

这套固件跑在 RFID 电动车上。单片机读卡片文字，再让语音模块念出来。

文档用 Obsidian 打开。建议从这一页开始，顺着链接往下看。

## 先看哪几页

- [[00-总览]]：产品做什么、分几层、数据怎么走
- [[01-硬件对照]]：板子上的插座、开关和单片机脚怎么对应
- [[02-主循环]]：上电后程序怎么转
- [[03-读卡到播报]]：一张卡从读到念的全过程

## 代码在哪

- [[src-main.c]]：程序入口
- [[src-app.c]]：读卡结果送到语音
- [[src-board_stm32.c]]：这块板的脚和串口
- [[include-app.h]]：应用层对外的两个函数
- [[include-app_config.h]]：能调的数字
- [[include-board.h]]：板级接口
