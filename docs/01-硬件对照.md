# 硬件对照

引脚来自嘉立创工程网表，不是丝印图。改线之前先对这张表。

## 单片机

| 位号 | 器件 | 说明 |
|---|---|---|
| `U11` | STM32F103C8T6 | 主控，48 脚，64 KB Flash |

时钟按外部 8 MHz 晶振、PLL 到 72 MHz。APB1 是 36 MHz。

## 功能件

| 位号 | 单片机脚 | 固件用途 |
|---|---|---|
| `H1` RFID 插座 | `PA9` TX、`PA10` RX | USART1，9600 |
| `U7` 语音插座 | `PA2` TX、`PA3` RX | USART2，9600，只发不收 |
| `led灯` | `PA8` | 读卡指示，低电平点亮 |
| `U2` DRV8837 | `PA0`、`PA1` | 电机 PWM，默认关闭 |
| `电机` / `电机1` | `OUT1`、`OUT2` | 电机接线柱 |

## 下载和复位

| 位号 | 脚 | 说明 |
|---|---|---|
| `SWD` | `PA13`、`PA14`、`NRST` | 烧录和调试口，程序不碰 |
| `SW3` | `NRST`、地 | 复位键，程序不碰 |
| `SW1` | 不接 MCU 脚 | 播报器电源通断，程序不碰 |

## 电源件

电池、超级电容、输入输出排针都由硬件完成，固件不管。

## 串口接线

语音模块接 `U7`。模块 RX 接单片机 `PA2`，模块 TX 接单片机 `PA3`。
`SW1` 管播报器电源。关上时模块没电，程序仍会往串口发数据。

读卡器接 `H1`。模块 TX 接单片机 `PA10`，模块 RX 接单片机 `PA9`。

## 和代码的关系

- 串口和灯在 [[src-board_stm32.c]] 里配。
- 能调的数字在 [[include-app_config.h]] 里。
- 板级对外接口在 [[include-board.h]] 里。

## 注意

- 指示灯按低电平点亮来写。灯常亮或不亮，先查 `PA8` 极性。
- 电机驱动的唤醒脚不在 MCU 上。只开 PWM，电机不一定转。
- 晶振不起振时程序会停住，灯和串口都没反应。
