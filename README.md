# 2027 工创赛控制软件

这是 RFID 电动车的控制固件。

单片机读卡片上的文字，再从语音模块念出来。读到卡时，板上 `PA8` 的比赛灯会亮一小会儿。电机默认会转。上电后等多久再转，由 `PB1` 旋钮决定。

读卡协议和读卡状态机在 `lib/rfid_core` 里。那是库，不要改。库里还有语音队列，应用层不用，改走立刻播报。

应用层主要是这些文件：

- `src/main.c`：上电入口
- `src/app.c`：读到卡立刻发文字
- `src/announce.c`：到点立刻播报，不排队
- `src/soft_start.c`：把旋钮读数换成等待时间
- `src/board_stm32.c`：这块板的脚、串口、旋钮和电机
- `include/app_config.h`：能调的数字

## 能做什么

1. 每隔约 80 ms 问一次「有没有卡」。
2. 读到卡后，读数据块，拼出 GB2312 文字。
3. 读到就念。下一张不同的卡会打断上一句。
4. 同一张卡一直放着，只念一次。拿走再放回来，会再念一次。
5. 点亮 `PA8` 约 500 ms，方便现场看有没有读到。

## 和这块板怎么对应

引脚来自嘉立创工程网表，不是丝印图。这块板是 STM32F103C6T6。

| 板上器件 | 单片机脚 | 固件里的用途 |
|---|---|---|
| `U11` STM32F103C6T6 | — | 主控，32 KB Flash |
| `H1` RFID 插座 | `PA9` TX、`PA10` RX | USART1，9600 |
| `U7` 语音插座 | `PA2` TX、`PA3` RX | USART2，9600，只发不收 |
| `led灯1` | `PA8` | 比赛灯，低电平点亮 |
| `R11` / `R4` / `C4` | `PB1` | 缓启动时间旋钮，上电读一次 |
| `U2` DRV8837 | `PA0`、`PA1` | 电机 PWM，默认打开 |
| `电机` / `电机1` | `OUT1`、`OUT2` | 电机接线柱 |
| `SWD` | `PA13`、`PA14`、`NRST` | 下载和调试，程序不碰 |
| `SW3` | `NRST`、地 | 复位键，程序不碰 |
| `SW1` | 不接 MCU 脚 | 播报器电源通断，程序不碰 |

电源、电池、超级电容、输入输出排针都由硬件完成，固件不管。

## 怎么编译

在 `firmware` 目录里。

本机先跑测试，不插板子：

```sh
sh scripts/run_host_tests.sh
```

交叉编译只把 C6 当这块板的默认：

```sh
pio run -e stm32f103c6
```

烧录走 `SWD` 口，下载器按 CMSIS-DAP 配的：

```sh
pio run -e stm32f103c6 -t upload
```

要用 ST-Link，把 `platformio.ini` 里的 `upload_protocol` 改成 `stlink`。

`stm32f103c8` 环境留给别的芯片。不要把 C8 固件刷到这块 C6 板上。

## 电机

电机默认打开。首次上板必须架空车轮，并准备断电。

时序：上电后先按旋钮等待，再约 1 秒升到目标转速，最长跑 10 分钟后自动停。等待范围默认是 10 秒到 10 分钟，在 `app_config.h` 里改。

驱动芯片的唤醒不在 MCU 脚上。只出 PWM，电机仍可能不转。先确认板上开关和驱动接线。

## 改参数

改 `include/app_config.h`，然后重新编译。常用项：

| 名字 | 默认 | 含义 |
|---|---|---|
| `APP_RFID_BAUD_RATE` | 9600 | RFID 波特率 |
| `APP_TTS_BAUD_RATE` | 9600 | 语音波特率 |
| `APP_RFID_POLL_INTERVAL_MS` | 80 | 空闲时多久问一次卡 |
| `APP_LED_MARK_DURATION_MS` | 500 | 比赛灯亮多久 |
| `APP_TTS_SET_SPEED_ON_STARTUP` | 1 | 开机是否发语速命令 |
| `APP_SOFT_START_MIN_MS` | 10000 | 旋钮最小等待 |
| `APP_SOFT_START_MAX_MS` | 600000 | 旋钮最大等待 |
| `APP_ENABLE_MOTOR` | 1 | 电机是否打开 |

不要为了改风格去动 `lib/rfid_core`。

## 使用时注意

- 卡片文字按 GB2312。非法双字节不会送给语音。
- 语音模块要接在 `U7`。TX/RX 和单片机交叉：模块 RX 接 `PA2`，模块 TX 接 `PA3`。
- `SW1` 管播报器通断。关上时程序仍会往 `PA2` 发数据，但模块没电，听不见。
- 读卡器接在 `H1`。模块 TX 接 `PA10`，模块 RX 接 `PA9`。
- 比赛灯按低电平点亮来写。若灯常亮或不亮，先查 `PA8` 极性和灯座接线。
- 时钟按板上 8 MHz 晶振、72 MHz 主频。晶振不起振时程序会停住，灯和串口都没反应。
- `board_rfid_rx_overflow_count()` 若一直在涨，说明主循环慢了，RFID 字节丢掉过。
