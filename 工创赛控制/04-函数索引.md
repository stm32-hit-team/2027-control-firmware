# 函数索引

这一页把每个源文件的函数列全。点文件名进去看细节。

## src/main.c

见 [[src-main.c]]。

| 函数 | 做什么 |
|---|---|
| `main` | 配硬件，建业务，然后一直转 |

## src/app.c

见 [[src-app.c]]。

| 函数 | 做什么 |
|---|---|
| `app_init` | 先准备语音，再准备读卡 |
| `app_process` | 倒空缓冲，推进读卡、语音和板级定时 |
| `app_write_rfid` | 把读卡命令发到 RFID 串口 |
| `app_write_tts` | 把语音文字发到语音串口 |
| `app_accept_tag` | 文字入队，入队成功就点灯 |
| `app_on_rfid_event` | 读卡事件入口，只处理「读到卡」 |
| `app_load_reader_config` | 用配置覆盖库的默认读卡节奏 |

## src/board_stm32.c

见 [[src-board_stm32.c]]。

### 对外

| 函数 | 做什么 |
|---|---|
| `board_init` | 配时钟、灯、两路串口，可选电机 |
| `board_millis` | 返回开机后的毫秒数 |
| `board_idle` | 睡到下一次中断 |
| `board_rfid_write` | 往 RFID 串口发数据 |
| `board_rfid_read_byte` | 从 RFID 缓冲取一字节 |
| `board_tts_write` | 往语音串口发数据 |
| `board_mark_tag` | 点亮 PA8，并记下熄灭时刻 |
| `board_process` | 到点关灯，可选推电机 |
| `board_rfid_rx_overflow_count` | 返回丢字节的累计次数 |

### 内部

| 函数 | 做什么 |
|---|---|
| `board_time_reached` | 判断时间是否到点，处理 32 位翻转 |
| `board_fail_stop` | 时钟或串口失败时停住 |
| `board_configure_clock` | 外部 8 MHz 晶振到 72 MHz |
| `board_configure_led` | 配 PA8 为输出 |
| `board_led_write` | 写 PA8 电平 |
| `board_led_on` | 点亮 PA8 |
| `board_led_off` | 熄灭 PA8 |
| `board_configure_uart_gpio` | 配两路串口的脚 |
| `board_fill_uart` | 填一路串口的参数 |
| `board_configure_rfid_uart` | 配 USART1 |
| `board_configure_tts_uart` | 配 USART2 |
| `board_arm_rfid_irq` | 打开 USART1 接收中断 |
| `board_configure_uarts` | 串口配置的总入口 |
| `board_validate_tx` | 发送前检查指针和长度 |
| `board_uart_send` | 调 HAL 发送，超时返回错误 |
| `board_ring_next` | 环形缓冲下一个下标 |
| `board_ring_push` | 中断里存一字节 |
| `board_ring_take` | 主循环取一字节 |
| `board_motor_apply` | 写电机占空比 |
| `board_configure_motor` | 配 TIM2 两路 PWM |
| `board_process_motor` | 推进电机时序 |

### 中断入口

| 函数 | 做什么 |
|---|---|
| `USART1_IRQHandler` | USART1 中断，转给 HAL |
| `SysTick_Handler` | 每 1 ms 累加毫秒计数 |
| `HAL_UART_RxCpltCallback` | 收完一字节，存进环形缓冲 |
| `HAL_UART_ErrorCallback` | 串口出错后重启接收 |
