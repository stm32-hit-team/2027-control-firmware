# 读卡到播报

这一页讲一张卡从靠近到被念出来的全过程。

## 状态机

读卡流程在库 `lib/rfid_core` 里。应用层只在 [[src-app.c]] 里接结果，立刻发文字。

```mermaid
stateDiagram-v2
    [*] --> IDLE
    IDLE --> WAIT_UID: 到点发寻卡
    WAIT_UID --> IDLE: 无卡或超时
    WAIT_UID --> WAIT_BLOCK: 读到 UID
    WAIT_BLOCK --> WAIT_BLOCK: 读下一块
    WAIT_BLOCK --> WAIT_DISPATCH: 文字拼好
    WAIT_DISPATCH --> WAIT_REMOVAL: 文字发出去
    WAIT_DISPATCH --> WAIT_DISPATCH: 发送失败，稍后重试
    WAIT_REMOVAL --> WAIT_REMOVAL: 卡还在
    WAIT_REMOVAL --> IDLE: 确认拿走
```

## 一张卡的时间线

```mermaid
sequenceDiagram
    participant M as 单片机
    participant R as 读卡器
    participant T as 语音

    M->>R: 寻卡命令
    R-->>M: 有卡，回 UID
    M->>R: 读数据块
    R-->>M: 回文字
    M->>T: 立刻发当前文字
    M->>M: 点亮 PA8
    M->>R: 反复确认卡还在
    R-->>M: 连续几次无卡
    M->>M: 允许下次再念
```

## 关键规则

- 读到就念。下一张不同 UID 的卡会马上改念，打断上一句。
- 同一张卡一直放着，只念一次。靠 UID 判重。
- 拿走再放回，会再念一次。靠连续几次读不到来确认。
- 串口没发出去才重试。读卡器会保住这张卡。这不是排队。
- 非法 GB2312 不会送给语音。
