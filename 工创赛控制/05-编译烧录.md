# 编译和烧录

在仓库根目录操作。`main` 分支是 PlatformIO 工程。只用 Keil 的人看 [[08-Keil工程]]，不要在本分支里手搭。

## 先跑本机测试

不插板子，只测协议、读卡状态机、立刻播报和旋钮换算：

```sh
sh scripts/run_host_tests.sh
```

看到 `All native firmware tests passed.` 就是过了。本机需要 `clang`。

## 编译

默认按这块板的 C6 来：

```sh
pio run -e stm32f103c6
```

手上是 C8，改用：

```sh
pio run -e stm32f103c8
```

生成文件：`.pio/build/stm32f103c6/firmware.bin` 和 `firmware.hex`。

**不要把 C8 固件刷到 C6 板上。** C8 按 64 KB Flash 链接，这块板只有 32 KB。

## 烧录

走 `SWD` 口。`platformio.ini` 里 `upload_protocol` 已是 `stlink`。

```sh
pio run -e stm32f103c6 -t upload
```

下载器是 CMSIS-DAP 时，把 `platformio.ini` 里那一行改成 `cmsis-dap`。

SWD 接 `PA13`、`PA14`、`NRST`、地、3.3 V。

烧录成功后芯片会复位。约 3 秒后电机可能转，先架空车轮。

## 电机

电机默认打开。`APP_ENABLE_MOTOR` 为 1。

时序：上电先停 3 秒，再约 3 秒爬到目标转速。跑多久后停，由 `PB1` 旋钮决定，默认 10 秒到 10 分钟。

`platformio.ini` 里的 `stm32f103c6_motor_check` 只是再显式加上 `-DAPP_ENABLE_MOTOR=1`。现在默认已经打开，一般不用专门切这个环境。

驱动芯片的唤醒不在 MCU 脚上。只出 PWM，电机仍可能不转。先确认板上开关和驱动接线。

首次上板必须架空车轮，并准备断电。

## 改参数

改 [[include-app_config.h]]，然后重新编译。常用项：

| 名字 | 默认 | 含义 |
|---|---|---|
| `APP_RFID_BAUD_RATE` | 115200 | RFID 工作波特率 |
| `APP_TTS_BAUD_RATE` | 9600 | 语音波特率 |
| `APP_RFID_POLL_INTERVAL_MS` | 40 | 空闲时多久问一次卡 |
| `APP_LED_MARK_DURATION_MS` | 500 | 指示灯亮多久 |
| `APP_TTS_SET_SPEED_ON_STARTUP` | 1 | 开机是否发语速命令 |
| `APP_MOTOR_START_LATE_MS` | 3000 | 上电后多久起步 |
| `APP_MOTOR_RAMP_MS` | 3000 | 爬升用多久 |
| `APP_ENABLE_MOTOR` | 1 | 电机是否打开 |

旋钮只管停车，不管起步。起步固定 3 秒。

## 现场检查

1. 上电约 3 秒，电机起步；再约 3 秒到巡航。
2. 打开 `SW1`。把卡放到读卡区，灯应闪一下并马上播报。
3. 同一张卡一直放着只念一次。拿走再放，会再念。
4. 旋钮改变的是多久停，不是等多久才起步。
