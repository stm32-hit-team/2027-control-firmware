# 编译和烧录

在 `firmware` 目录里操作。

## 先跑本机测试

不插板子，只测库：

```sh
sh scripts/run_host_tests.sh
```

看到 `All native firmware tests passed.` 就是过了。

## 编译

默认按这块板的 C6 来：

```sh
pio run -e stm32f103c6
```

手上是 C8，改用：

```sh
pio run -e stm32f103c8
```

## 烧录

走 `SWD` 口，下载器按 CMSIS-DAP 配的：

```sh
pio run -e stm32f103c6 -t upload
```

用 ST-Link，把 `platformio.ini` 里的 `upload_protocol` 改成 `stlink`。

## 电机测试

默认电机不转。要测，用这个环境，并架空车轮、准备断电：

```sh
pio run -e stm32f103c6_motor_check
```

打开后：先停 3 秒，再约 1 秒升到目标转速，最长跑 10 分钟自动停。

驱动芯片的唤醒不在 MCU 脚上。只烧这个环境，电机仍可能不转。先确认板上开关和驱动接线。

## 改参数

改 [[include-app_config.h]]，然后重新编译。常用项：

| 名字 | 默认 | 含义 |
|---|---|---|
| `APP_RFID_BAUD_RATE` | 9600 | RFID 波特率 |
| `APP_TTS_BAUD_RATE` | 9600 | 语音波特率 |
| `APP_RFID_POLL_INTERVAL_MS` | 80 | 空闲时多久问一次卡 |
| `APP_LED_MARK_DURATION_MS` | 500 | 指示灯亮多久 |
| `APP_TTS_SET_SPEED_ON_STARTUP` | 1 | 开机是否发语速命令 |
